⚠ WINDOWS: Wrong USB driver — ANT+ won't work until fixed
One-time fix (takes 2 min):
1. Download & open Zadig (free tool)
2. Plug in your ANT+ USB stick
3. In Zadig: Options → List All Devices
4. Select "ANT USB Stick 2" (or ANT USB Stick / Dynastream)
5. Set driver to WinUSB → click "Replace Driver"
6. Close Zadig, then re-run cmd as Administrator:
   node server.js
